# Foodfight Arena — что дальше (соло-часть)

Состояние на сейчас: круглая арена с падением, движение/прыжок/спринт, еда падает
с неба → подбор касанием → бросок дугой в курсор, урон+кнокбэк, манекен для тестов,
ловушки (сковородка, банан), HUD (таймер, здоровье, экран конца раунда).

## Чего не хватает до "играбельно вдвоём" (важное)

- [ ] **Спавн-поинты на двоих**: сейчас игрок стартует и респавнится в центре.
      Нужны две точки по краям арены (Marker3D в Arena.tscn), респавн на своей стороне.
- [ ] **Урон игроку уже работает** (`take_hit` есть), но бить его пока некому —
      проверится при появлении P2. Свой снаряд по себе не бьёт (`shooter`-чек).
- [ ] **Победа по ринг-ауту**: сейчас падение = -1 HP и телепорт назад. Решить,
      так и оставить или сделать мгновенный проигрыш при падении (стиль Smash).
- [ ] **Экран конца раунда** перезагружает сцену кнопкой — для сетевой игры
      понадобится другой флоу (рестарт по команде хоста).

## Геймплей-идеи (быстрые победы)

- [ ] **Типы еды**: тяжёлая (больше кнокбэк, летит медленнее), лёгкая (быстрая, слабая),
      арбуз-«бомба» (AoE). FoodItem уже держит цвет — расширить до типа+параметров.
- [ ] **Заряженный бросок**: держать ЛКМ — дальше/сильнее летит.
- [ ] **Урон сверху**: падающая еда сейчас безвредна — можно оглушать того, кому на голову.
- [ ] **Сужающаяся арена**: радиус пола уменьшается к концу таймера — форсит финал.
- [ ] **Счёт по раундам**: best of 3 вместо одного раунда.
- [ ] **Ещё ловушки**: лужа масла (зона скольжения), конфорка (тикающий урон на месте).

## Полиш (заглушками, без финального арта)

- [ ] Партиклы/сплэш при попадании и разбивании еды об пол.
- [ ] Звуки-заглушки: бросок, попадание, подбор, скольжение, падение, гонг раунда.
- [ ] Squash & stretch у еды, анимация подбора (подлёт к рукам).
- [ ] Круглая тень-блоб под игроком — читаемость прыжка.
- [ ] HUD: иконка еды в руках, отсчёт «3-2-1» на старте раунда.

## Технические заметки (для сетевой части)

- Чтение инпута в `player_controller.gd` отделено от применения движения —
  оборачивается в authority-чек без переписывания остального.
- Контракты через `has_method`: `take_hit(damage, knockback)`, `apply_knockback(impulse)`,
  `slip(duration)`, `pick_up_food(color)` — сервер может дёргать их напрямую.
- HUD находит игрока/манекена по NodePath из инспектора — при спавне игроков из кода
  ссылки нужно будет передавать динамически.
- FoodSpawner случайный — для сети понадобится общий seed или спавн только на хосте.
- Все скрипты теперь в `Scripts/` (с большой буквы) — новые класть туда же,
  папку `scripts/` не создавать (Windows не различает регистр, экспорт на Linux сломается).
- После открытия проекта в редакторе коммитить появившиеся `.uid`-файлы.
