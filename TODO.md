# Foodfight Arena — что дальше (соло-часть)

Состояние: круглая сужающаяся арена с падением, типы еды через ресурсы,
заряженный бросок, урон от падающей еды, best of 3, ловушки ×4, HUD со счётом.

## Сделано ✅

- [x] **Типы еды** — `FoodType`-ресурсы в `assets/food/` (помидор — лёгкий/быстрый,
	  сыр — обычный, тыква — тяжёлая (2 урона, большой кнокбэк), арбуз — AoE-бомба).
	  **Замена заглушек на модельки**: открыть .tres, положить Mesh артиста в поле
	  `mesh`, поправить `visual_scale`/`rest_height` — код не трогается, меш
	  автоматически применяется к пикапу, еде в руках и снаряду.
- [x] **Заряженный бросок** — держать ЛКМ: маркер прицела растёт и краснеет,
	  отпустить — до +80% дальности и +50% кнокбэка (`charge_*` в инспекторе игрока).
- [x] **Урон сверху** — падающая еда бьёт по голове (1 урон + подброс); тень-метка
	  на полу начинается широкой и сжимается к точке удара — время среагировать есть.
- [x] **Сужающаяся арена** — после 40% раунда пол плавно сжимается до 55% радиуса
	  (`shrink_start`/`min_scale` на ноде Floor). Еда, оставшаяся без пола, падает в пропасть.
- [x] **Счёт по раундам** — best of 3: счёт над таймером, экран раунда/матча,
	  «Следующий раунд» сохраняет счёт (static-переменные в hud.gd), «Новый матч» сбрасывает.
- [x] **Ловушки**: сковородка (кнокбэк), банан (разовый слип + респавн),
	  лужа масла (постоянная зона скольжения), конфорка (тикающий урон + подброс, пульсирует).
- [x] **Спавн-поинты на двоих** — Marker3D `SpawnPoints/SpawnP1|P2` (±4.5 по X,
	  внутри финального радиуса сжатия), игрок и манекен стартуют и респавнятся каждый на своей стороне.
- [x] **Ринг-аут** — решено: падение = −1 HP + возврат на свою точку старта.

## Технические заметки (для сетевой части)

- Чтение инпута в `player_controller.gd` отделено от применения движения —
  оборачивается в authority-чек без переписывания остального.
- Контракты через `has_method`: `take_hit(damage, knockback)`, `apply_knockback(impulse)`,
  `slip(duration)`, `pick_up_food(food_type)` — сервер может дёргать их напрямую.
- HUD находит игрока/манекена/пол по NodePath из инспектора — при спавне игроков
  из кода ссылки передавать динамически.
- Ловушки НЕ сжимаются вместе с полом (лежат в корне арены): у края к концу раунда
  могут повиснуть над пропастью — выглядит терпимо, триггеры безвредны в воздухе.
- Все скрипты в `Scripts/` (с большой буквы) — папку `scripts/` не создавать
  (Windows не различает регистр, экспорт на Linux сломается).
- После открытия проекта в редакторе коммитить появившиеся `.uid`-файлы.
