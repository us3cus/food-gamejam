# TCP-сервер лобби

## Схема подключения

Godot-клиент подключается raw TCP к `onk.temten.me:7777`. TLS на игровом TCP по
текущей спецификации не используется. HTTPS-сайт продолжает работать отдельно
на `https://temten.me`.

На сервере Node.js-процесс слушает только loopback:

```text
Godot -> onk.temten.me:7777 -> nginx stream -> 127.0.0.1:7778 -> Node.js
```

Клиентский адрес задаётся в `project.godot`:

```ini
[network]
lobby/host="onk.temten.me"
lobby/port=7777
```

Локальный bind сервера задаётся переменными окружения:

```env
TCP_HOST=127.0.0.1
TCP_PORT=7778
TCP_LOG_LEVEL=debug
```

## Запуск

Требуется Node.js 20 или новее. Внешних npm-зависимостей нет.

```bash
cd server
cp .env.example .env
node --env-file=.env src/index.js
```

Проверка сервера:

```bash
cd server
npm test
```

`TCP_LOG_LEVEL=debug` выводит в stdout подключение клиента, его короткий ID и
типы TCP-пакетов. Не оставляйте этот режим включённым без необходимости.

## Диагностика клиента

Клиент выводит состояние TCP прямо на экране лобби и дублирует его в
`user://logs/network.log`. В редакторе Godot путь можно открыть через
**Project → Open User Data Folder**. В логе видны адрес, переходы статусов,
тайм-ауты, ошибки чтения/записи и типы JSON-пакетов; payload целиком не
сохраняется.

## Nginx stream

Конфигурация должна находиться в контексте `stream`, а не внутри HTTP virtual
host. Если nginx установлен модульно, должен быть загружен stream-модуль.

```nginx
stream {
    upstream foodfight_tcp_backend {
        server 127.0.0.1:7778;
    }

    server {
        listen 7777;
        proxy_connect_timeout 5s;
        proxy_timeout 1h;
        proxy_pass foodfight_tcp_backend;
    }
}
```

После изменения:

```bash
sudo nginx -t
sudo systemctl reload nginx
```

Порт `7778` не нужно открывать во внешнем firewall: он привязан к
`127.0.0.1`. Снаружи доступен только `7777/tcp`.

## Протокол

Каждый пакет — один UTF-8 JSON-объект и символ `\n`. Это важно, потому что TCP
является потоком байтов и не сохраняет границы сообщений. Максимальный размер
буфера одного пакета — 1 MiB.

Оболочка пакета:

```json
{"type":"lobby.create","request_id":2,"payload":{}}
```

Основной сценарий:

1. `session.hello` — версия протокола и имя игрока.
2. `lobby.create` с настройками или `lobby.join` с шестизначным кодом.
3. Сервер рассылает `lobby.updated` при составе, готовности или настройках.
4. Гости отправляют `lobby.ready`.
5. Хост отправляет `lobby.start`.
6. Сервер проверяет минимум двух игроков и готовность всех гостей, затем
   рассылает `lobby.started` с общими `match_id`, `seed` и настройками.

Клиент поддерживает серверы как с полем `can_start` в снимке лобби, так и без
него: во втором случае готовность вычисляется по массиву `players`, при этом
готовность хоста не требуется. Если хост находится в лобби один, кнопка
`Тестовый запуск` освобождает серверное лобби и открывает локальную арену с
тренировочным манекеном. Этот режим не ослабляет серверную проверку обычного
сетевого старта.

Поддерживаемые запросы:

| Тип | Payload |
| --- | --- |
| `session.hello` | `{ "protocol": 1, "player_name": "Игрок" }` |
| `lobby.create` | `{ "settings": { "max_players": 2, "round_time": 90, "wins_to_match": 2 } }` |
| `lobby.join` | `{ "lobby_id": "ABC234" }` |
| `lobby.settings` | `{ "lobby_id": "ABC234", "settings": { ... } }` |
| `lobby.ready` | `{ "lobby_id": "ABC234", "ready": true }` |
| `lobby.invite` | `{ "lobby_id": "ABC234" }` |
| `lobby.start` | `{ "lobby_id": "ABC234" }` |
| `lobby.leave` | `{ "lobby_id": "ABC234" }` |

Сервер хранит лобби в памяти. При выходе хоста права переходят следующему
игроку; пустое лобби удаляется. Лимиты настроек и право старта проверяются на
сервере, а не доверяются интерфейсу клиента.

## Граница текущей реализации

TCP-сервер авторитетно управляет сессией, лобби, настройками, готовностью и
единым моментом старта. После `lobby.started` клиенты открывают арену и применяют
одинаковые длительность раунда, число побед и seed. Синхронизация перемещений,
снарядов и результатов раунда — следующий слой игрового протокола и в этот
сценарий начала матча не входит.
